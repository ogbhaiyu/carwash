## 🚗 About The Project

Bhai was an ex-unicorn tech founder whose visa clock ran out after FTX collapsed. Armed with a bucket, a pressure washer, a cardboard sign, and a Robinhood Wallet, he set up shop directly in front of the seized FTX Global Headquarters in Nassau, Bahamas to wash tech bro rides on-chain.

### ✨ Key Features
- **🎮 Interactive 3D Canvas**: Built with Three.js featuring voxel cars, procedural materials, dynamic reflections, and interactive orbit/zoom.
- **🏎️ Fleet of Rides**:
  - *The VC's Muddy Tesla Model Y* (`AI-CHAD`)
  - *Palo Alto CyberTruck* (`EL0N-M5K`)
  - *SBF's '04 Beige Corolla* (`10X-ALAMEDA`)
  - *SBF's Seized Lambo Aventador* (`WAGMI-RIP`)
- **🕺 4-Phase Detailing Sequence**:
  1. *Generative Foam Cannon* (High-density soap particles)
  2. *138 BPM Bhangra Rim Scrub* (Bhai vigorously scrubbing rims with Vim Bar)
  3. *High-Pressure Hydro Jet Rinse* (Silicon Valley mud stripped clean)
  4. *On-Chain Sparkle & Confetti Finish* (Spotless mirror clearcoat)
- **🔊 Procedural Sound Design**: 100% Web Audio API synthesized audio (dual-tone European car horn, pressure washer pumps, water fizz, sponge squeaks, cash register chime).
- **💳 Robinhood Crypto Checkout**: Clean QR code generation for SOL, ETH, BTC, and DOGE with instant invoice generation.

## 🛠️ Tech Stack

- **Three.js** - 3D scene, voxel meshes, procedural textures, particle engines.
- **Web Audio API** - Custom synthesized audio graph (oscillators, biquad filters, white noise buffers).
- **Vite** - Lightning-fast frontend build tooling.
- **QRCode** - Clean on-chain wallet QR code generator.
- **Canvas Confetti** - Victory celebration particles.

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or newer recommended)
- `npm` or `yarn` / `pnpm`

### Local Setup
```bash
# Clone repository
git clone https://github.com/ogbhaiyu/carwash.git
cd carwash

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
